# Kronäng Juniorlag 2.0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver Kronäng Juniorlag 2.0 with bidirectional development notifications, Admin-managed staff and profile images, mobile news publishing with ownership rules, and safe local hiding of SportAdmin calendar activities.

**Architecture:** Extend the existing Supabase-backed systems instead of replacing them. Keep system roles separate from presentation roles, use RPC/RLS for privileged writes, reuse `development_notifications` for personal unread state, reuse `team_staff`, `team_posts`, and `profiles.avatar_url`, and introduce a small local calendar-suppression table keyed by stable external event identity. Every slice follows red-green-refactor and is independently releasable.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Supabase Auth/Postgres/RLS/RPC/Storage, Node test scripts, GitHub Actions.
